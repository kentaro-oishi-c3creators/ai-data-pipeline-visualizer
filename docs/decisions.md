# Decisions

## 2026-09-30 — 小さな静的 React アプリ
Vite と React/TypeScript を採用。今回の中心は工程の説明と操作で、学習用 Starter の DB やサーバー機能は不要。実データの接続が決まった段階で構成を再検討する。

## 2026-09-30 — 判断例を二つ用意
標準ケースと、意味対応が曖昧な要確認ケースを切り替える。AI の提案と決定論的な処理、人的承認の境界を具体的に示すため。実案件のルール確定後に文言を見直す。

## 2026-09-30 — 分岐実験は固定の架空シナリオ
選択が下流へ及ぼす影響を触って理解できるようにする。値引き後 1,800 を期待値と明示し、一致はこのサンプル内だけの結果とする。実案件の定義と入力が揃ったときに実データへ置き換える。
